# Sharvee Shrotriya — Portfolio

A responsive, dependency-free portfolio for https://sharvee-shrotriya.github.io/.

## Local preview

Run `python -m http.server 4173 --bind 127.0.0.1` from this folder and open http://127.0.0.1:4173.

## Files

- `index.html`: résumé-based content, projects, experience, and contact links.
- `styles.css`: responsive visual design.
- `script.js`: project filters and accessible mobile navigation.
- `Sharvee_Shrotriya_Resume.pdf`: downloadable source résumé.
- `favicon.svg`: portfolio monogram.
- `.nojekyll`: direct static serving on GitHub Pages.

## Publishing

Publish the root of the `main` branch in the public `sharvee-shrotriya/sharvee-shrotriya.github.io` repository with GitHub Pages. There is no build step and no secret or API key requirement.

The retail dashboard remains at https://sharvee-shrotriya.github.io/retail-analytics-portfolio/ and opens in a separate browser tab from the portfolio. Its repository is independent; no dashboard files need to be relocated.

## Content sources

Professional history and metrics come from the supplied Sharvee_Shrotriya_Resume.pdf. Project descriptions use the existing retail site and public repository READMEs. The influencer-loyalty project is labeled research in progress; the OTIF project uses synthetic data. The cover illustrations are conceptual graphics, not product screenshots or measured charts.

Update the résumé PDF and matching HTML content together when changing career details. Keep project URLs current. Typography loads from Google Fonts with system fallbacks.
